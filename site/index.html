What else Whistle does

While you're working

Drafts per pane
Each pane keeps its own unsent draft. Switch between agents and every reply waits where you left it.
Pictures
Attach a screenshot or photo while composing. The phone shrinks it and drops camera metadata before it goes to your PC.
Review changes
See what an agent changed in its checkout since the last commit, file by file, with the diff.
Terminal history
Swipe back through everything the pane printed, or copy it as plain text. Latest takes you back to the cursor.

Safe by default

Watching comes first
Opening a pane never resizes or focuses your desktop terminal. Typing starts only after you tap Take control, and a reconnect never resends anything.
Your existing sessions
Whistle works with the agents and panes you already run in Herdr. It adds no model calls of its own.
Runs on your computer
Whistle runs on your PC and reaches your phone over your private Tailscale network.
Paired phones only
Each phone pairs once by scanning a single-use QR code. You can list and revoke paired devices at any time.

How to download

Which processor do I have?

Run uname -m on the PC. x86_64 means x86-64, the usual choice for desktops and laptops. aarch64 means ARM64, as on a Raspberry Pi or an ARM laptop. Pick the matching one with the switch above, and every file name and command on this page follows it.

Which file should I pick?

One command
The easiest. It picks your processor, checks the download and starts Whistle for you. It never asks for root.
A package
For Debian, Ubuntu, Fedora, openSUSE and Arch. Your package manager knows about Whistle and can remove it cleanly.
The single file
The raw program, nothing wrapped around it. It works on any Linux with systemd and needs no root at all.
The archive
The same program, with the README and license, packed as a .tar.gz.

Install the single file

  1. Download it, and the checksums from the same release.

    curl -fLO https://github.com/__WHISTLE_REPOSITORY__/releases/latest/download/whistle-linux-x64
curl -fLO https://github.com/__WHISTLE_REPOSITORY__/releases/latest/download/SHA256SUMS

  2. Check that the file is intact. It should print OK.

    sha256sum --check --ignore-missing SHA256SUMS

  3. Make it runnable and install it. Whistle copies itself into ~/.local/share/whistle, adds a whistle command to ~/.local/bin and starts on your Tailscale address. You can delete the download afterwards.

    chmod +x whistle-linux-x64
./whistle-linux-x64 install --host "$(tailscale ip -4)" --now

With the archive, unpack it first and run the program inside the same way:

tar -xzf whistle-linux-x64.tar.gz
./whistle-__WHISTLE_VERSION__-linux-x64/whistle install --host "$(tailscale ip -4)" --now

To upgrade, download the new file and run the same install command again. Paired phones stay paired.

Set it up on your computer

  1. Install Whistle on the PC

    Use the one-line installer or a package from above. The PC needs Linux with systemd, Herdr for your agents, and Tailscale on both the PC and your phone.

  2. Start the service

    The one-line installer already did this. After a package install, run this once as your regular user. Whistle starts at login and listens only on your Tailscale address.

    whistle install --host "$(tailscale ip -4)" --now

  3. Pair your phone

    Run the pair command on the PC and scan the QR code with your phone's camera. The code works once and expires after five minutes.

    whistle pair

Alerts and installing Whistle as a phone app need HTTPS. The README shows how with Tailscale Serve, along with upgrades and safety notes.

This website only describes Whistle. It has no login, no terminal connection and no access to your computer. Pair your phone with the Whistle on your own PC.
