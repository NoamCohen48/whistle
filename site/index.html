Get started

The work stays on your PC.

Watch by default
Opening a pane does not focus or resize your desktop terminal. Control always needs an explicit tap.
Use your existing panes
Whistle connects to Herdr. Your agents and terminal sessions keep running on your computer.
Keep input intentional
Drafts stay separate per pane. Reconnecting never replays input or automatically takes control.

Run it on your own computer.

The host needs Linux and Herdr. Build from the repository, or download the Linux x64 build from a successful main-branch Actions run.

Follow the repository README for installation and private network access. Pair your phone with the host you run, not this website.
